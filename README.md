# 📚 Student Study Tracker

A simple beginner-friendly web project for managing study tasks.

## Features
- Add study tasks
- Add subject names
- Set a deadline
- Set task priority
- Mark tasks as completed
- Filter tasks by status
- Delete individual tasks
- Clear all tasks
- Automatically saves tasks using browser Local Storage
- Responsive design for desktop and mobile

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage API

## How to Run
Open `index.html` in a web browser. No server or installation is required.
